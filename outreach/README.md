# 営業メッセージ作成システム（ホテル・介護事業者向け）

株式会社キレイシアから、ホテル・介護事業者などの法人に向けて営業メールを送るための
「リード管理 → 文面自動生成 → Gmail下書き作成 → 人が確認して送信」という半自動の仕組みです。

**全自動送信は行いません。** 最終的な送信ボタンは必ず人が押します。これは誤送信や法令違反
（下記）を防ぐための意図的な設計です。

## 全体の流れ

1. **リード収集**（半自動リサーチ）
   `leads.csv` に、営業先候補（ホテル・介護施設の運営会社）を1件ずつ追加する。
   追加は次のいずれかの方法で行う。
   - 自分で調べて手入力する
   - Claude（このリポジトリのセッション）に「○○市のホテルを1件調べて追加して」のように
     依頼する。Claudeは該当企業の公式サイトを実際に確認し、公開されている問い合わせ先
     （メールアドレス or 問い合わせフォームURL）を出典つきで登録する。
     **複数件をまとめて自動収集・スクレイピングすることはしない。** 必ず1件ずつ出典を確認する。
2. **文面生成**
   `python3 generate_drafts.py` を実行すると、`status=researched` のリードについて
   業種別テンプレート（`templates/hotel.md` / `templates/nursing_care.md`）を使って
   文面を自動生成し、`drafts/` 以下にテキストファイルとして出力する。
   同時に `leads.csv` の該当行の `status` を `drafted` に更新する。
3. **Gmail下書きの作成**
   `drafts/` の文面を、Claudeに「Gmail下書きを作って」と頼むか、自分でGmailの下書きに
   コピーして作成する。件名・本文はそのまま使えるように生成される。
4. **人が確認して送信**
   Gmailの下書き一覧を自分の目で確認し、問題なければ自分で送信する。
   送信したら `leads.csv` の `status` を `sent` 、`date_contacted` を更新する。

## 法令・マナー上の注意（必ず守る）

- 対象は**公開されている法人の問い合わせ先**（会社サイトに掲載のメールアドレス／
  問い合わせフォーム）に限る。個人のメールアドレスや、非公開の情報を使わない。
- 特定電子メール法（迷惑メール防止法）に配慮し、本文に **送信者の氏名・会社名・住所・
  配信停止（お断り）の連絡方法** を必ず明記する（テンプレートに記載済み）。
- 問い合わせフォームへの**自動入力・自動送信ボットは作らない**。フォームしか窓口がない
  先は、人が手動でコピー＆ペーストして送信する。
- 同じ先に短期間で何通も送らない。断られたら `status=declined` にして再送しない。
- 大量の企業情報を無差別にスクレイピングしない。対応エリア（大阪・京都・兵庫・奈良）内の、
  自社サービスと関連性の高い先を少数ずつ、出典を確認しながら集める。

## ファイル構成

```
outreach/
  README.md              このファイル
  leads.csv               営業先リード一覧
  templates/
    hotel.md               ホテル業向け文面テンプレート
    nursing_care.md         介護事業者向け文面テンプレート
  drafts/                 generate_drafts.py の出力（Git管理対象外）
  generate_drafts.py       文面生成スクリプト
```

## leads.csv の列

| 列 | 内容 |
|---|---|
| id | 連番 |
| category | `hotel` または `nursing_care` |
| company_name | 企業・施設名（正式名称） |
| prefecture / city | 所在地（対応エリア内かの確認用） |
| contact_email | 公開されている問い合わせ用メールアドレス（なければ空） |
| contact_page_url | 問い合わせフォームのURL（メールが無い場合に使用） |
| source_url | 連絡先を確認した出典ページ（公式サイトのURL） |
| status | `new`→`researched`→`drafted`→`sent`→`replied` / `declined` |
| notes | 備考（担当者名・提案の切り口など） |
| date_added / date_contacted | 登録日・送信日 |

`status=example` の行はサンプルデータです。`generate_drafts.py` はこの行を無視します。
実際の営業先を追加するときは、必ずサンプル行は削除するか `status` を書き換えてください。

## 文面生成スクリプトの実行

```bash
cd outreach
python3 generate_drafts.py
```

外部ライブラリは使用しません（標準ライブラリのみ、`build_blog.py` と同じ方針）。
